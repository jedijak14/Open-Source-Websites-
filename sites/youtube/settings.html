Google account

Signing in grants read-only YouTube access (youtube.readonly): your channel, subscriptions, liked videos and playlists. A short-lived access token stays in this browser and is only sent to googleapis.com.

Profiles

Create multiple profiles under your Google account, each with their own watch history, recommendations, preferences, and API configuration — just like Netflix. Each profile can have its own YouTube API key and OAuth client ID.

Note: API keys and OAuth client IDs are now profile-specific. When you switch profiles, the active API key and client ID switch with you.

YouTube watch history

Google does not expose watch history through the YouTube Data API — no key or OAuth scope can read it. The only supported route is your own Google Takeout export, which OpenTube can import here.

  1. Open takeout.google.com, deselect everything, tick YouTube and YouTube Music.
  2. Choose JSON format, then export. Ads and non-video entries are filtered out on import.
  3. Unzip and pick watch-history.json (the HTML export also works).

Recommendations

The feed is ranked by a model this site builds itself, on this device, from what you actually watch — how much of it, likes, saves and subscriptions — plus any imported watch history and the Google account you connect. YouTube does not give apps your watch history, so this is the only way the algorithm can learn from it.

The model is stored per account: signing in with a YouTube account keeps that account's taste (its subscriptions and liked videos are folded in), and signing out returns to the anonymous one. It never leaves the browser — there is no server to send it to, and the read-only scope means nothing is ever written back to YouTube.

Ads & tracking

  • No ad slots. Nothing on this site renders or reserves space for advertising; there are no ad SDKs, pixels or beacons.
  • No analytics or trackers. No Google Analytics, no session recording, no third-party fonts or CDNs. Every request is served from this origin.
  • No cookies for advertising. OpenTube sets no cookies at all; preferences live in localStorage and the OAuth token in sessionStorage.
  • Privacy-preserving playback. Embeds use youtube-nocookie.com with rel=0 and modestbranding=1.
  • Strict Content-Security-Policy. The deployed host sends a CSP that only allows this origin plus googleapis.com, accounts.google.com and the YouTube embed frame — so an injected ad script could not load.

One honest exception: ads that YouTube itself plays inside its embedded player cannot be removed by this site — that is YouTube's player and its monetisation, and stripping it would breach their terms. Only YouTube Premium removes those. OpenTube never adds advertising of its own.

Connect live YouTube data

OpenTube can render its feed, search, channels and player from the real YouTube Data API v3 instead of the offline demo dataset.

  1. Create a key in the Google Cloud console and enable YouTube Data API v3.
  2. Restrict the key to HTTP referrers for this site (and localhost) so it cannot be used elsewhere.
  3. Paste it below. It is stored in this browser only and sent to googleapis.com — never to any other host.
