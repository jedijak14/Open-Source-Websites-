About OpenTube

OpenTube is an open-source video-platform demo built to show how far you can get with plain HTML, CSS and JavaScript. It is part of the Open Source Websites collection — hand-written clones of familiar sites, made without frameworks and without copying anyone's assets.

What works

  • Recommendations and categories. A chip bar filters the feed; the feed sorts by publish date.
  • A custom video player. Play, scrub with a buffered range, volume, playback speed, transcript captions, theater mode and fullscreen.
  • Chapters and keyboard shortcuts. Click a chapter to jump; k play/pause, j/l skip 10s, m mute, c captions, t theater, f fullscreen.
  • Channels. Home, Videos and About tabs, subscribe buttons and a subscription feed.
  • Search. Matches titles, descriptions, tags and channel names, with highlighted terms and channel results.
  • Library. Watch history with resume positions, Watch later, liked videos and subscriptions — all kept in localStorage.
  • Comments with sorting, likes and locally posted comments.
  • Light and dark themes, following your OS setting until you override it; responsive from phone to widescreen.

Demo data

Nine channels and eighteen videos are defined in assets/data.js. Every view count, subscriber figure and comment is invented. The thumbnails are generated photographs; the clips are synthesised ambient loops (ffmpeg gradients plus a sine chord) so playback works offline. Nothing here references a real person or brand.

How it is built

sites/youtube/
  src/layout.html        document shell
  src/partials/          header, icon sprite, menus, footer
  src/pages/             page bodies with a JSON meta block
  assets/                styles.css, app.js, data.js, thumbs, video
  scripts/build-pages.mjs   src/ → static .html
  scripts/build-media.sh    thumbnails + mp4 clips (ffmpeg)
  scripts/build-avatars.py  channel avatar SVGs
  server.mjs             small static server with byte-range support

node server.mjs rebuilds the pages, then serves the folder on port 4321. Because the output is plain static files, the same directory can be dropped on any hosting provider.
